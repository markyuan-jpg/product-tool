## 二、当前路线（v0.3 → 商业化）

按用户反馈和商业可行性排序：

### Step 1：OCR 图片/扫描件解析

**为什么先做：** 用户反馈"还不能商业化"的核心原因之一。工厂报价单大量是微信拍照或扫描件，目前完全不支持。

| 子任务 | 说明 | 工作量 |
|--------|------|:---:|
| 图片格式入口 | 前端上传区接受 jpg/png/webp；后端新增图片上传处理 | 小 |
| OCR 引擎接入 | 选型：PaddleOCR（免费离线，需 GPU/CPU）或百度 OCR API（按量付费） | 大 |
| 扫描件 PDF 检测 | PyMuPDF 判断 PDF 是否扫描件（文字量 < 阈值），是则走 OCR | 中 |
| 文字→解析器 | OCR 提取的文字走现有 PDF 文本解析器路径 | 中 |

**目标：** 微信拍照的报价单 → 拖进去 → 30 秒出结果。

---

### Step 2：解析准确率评测体系

**为什么先做：** 不知道 100 份真实工厂报价单能正确解析多少份。没有数据就没法说服用户"这工具靠谱"，也没法知道自己改 parser 是在改进还是退步。

| 子任务 | 说明 | 工作量 |
|--------|------|:---:|
| 收集样本 | 30-50 份真实工厂报价单（各种格式/行业） | 人工 |
| 人工标注 | 每份标注：型号、价格、规格、产品数量 | 人工 |
| 评测脚本 | 批量解析 → 对比标注 → 输出准确率（型号提取率、价格提取率、规格完整性、产品数匹配率） | 中 |
| CI 集成 | 每次 push 自动跑评测，低于阈值报警 | 小 |
| 结果面板 | 简单的 HTML 报告：每个文件的得分 + 总览 | 小 |

**目标：** 知道当前准确率基线，每次改 parser 有数据。

---

### Step 3：用户行为埋点

**为什么先做：** 没有数据就不知道用户在哪一步流失。改功能是瞎改。

| 子任务 | 说明 | 工作量 |
|--------|------|:---:|
| 后端埋点端点 | `POST /api/event` — 接收事件名 + 可选 payload，写日志或 SQLite | 小 |
| 前端关键事件 | `page_view` / `demo_click` / `upload_start` / `upload_success` / `upload_fail` / `parse_success` / `parse_empty` / `parse_timeout` / `generate_quotation` / `download` | 小 |
| 简单统计面板 | `/workspace` 内嵌的统计卡片：今日上传数、解析成功率、生成报价单数 | 中 |

**目标：** 知道每天多少人用、用到了哪一步、在哪断了。

---

### Step 4：新手引导 + 数据持久化提示

**为什么：** 新用户打开工作台一片空白，不知道第一步做什么 → 直接离开。

| 子任务 | 说明 | 工作量 |
|--------|------|:---:|
| 引导气泡 | 首次进工作台：3 步引导（上传文件 → 查看解析结果 → 生成报价单），点"知道了"后 localStorage 记录不再显示 | 中 |
| 数据提示横幅 | 顶部提示："数据保存在浏览器中，注册账号后可永久保存 → 免费注册" | 小 |
| 空状态优化 | 产品库为空时不显示空表格，显示友好插画 + "拖入第一个文件" 按钮 | 小 |

---

### Step 5：定价页 + 支付恢复

**为什么：** 不收钱 = 慈善项目。已有 Creem 集成，Nav 恢复定价链接即可。

| 子任务 | 说明 | 工作量 |
|--------|------|:---:|
| Nav 加定价链接 | 一行代码 | 小 |
| 支付入口可用 | 确认 Creem checkout 流程端到端可用 | 中 |
| Pro 功能差异化 | 当前所有功能免费，需定义哪些留给 Pro。建议：OCR 功能、无限产品库、优先解析 | 中 |

## 三、已知限制（当前版本）

| 类别 | 限制 | 影响 |
|------|------|------|
| 格式 | 不支持 .doc / 扫描件 PDF / 图片 | 工厂微信拍照的报价单无法处理 |
| 数据 | 匿名用户数据存 localStorage，清除后丢失 | 用户切换浏览器/清缓存后产品全丢 |
| 支付 | 支付休眠中，无收入 | 无法商业化 |
| 测试 | 无前端测试、无解析准确率评测 | 改代码不知道有没有破坏功能 |
| 分析 | 无用户行为埋点 | 不知道用户在哪流失 |
| 引导 | 无新手引导 | 新用户进来不知道做什么 |
| 性能 | 未做负载测试 | 不知道 VPS 能撑多少并发 |
| 安全 | 无邮箱验证、无 2FA | 注册安全底线未达标 |

## 四、不做（明确砍掉）

| 项目 | 原因 |
|------|------|
| 智能粘贴（AI 文本→产品） | DeepSeek API 不对外公开，前端已禁用 |
| .doc 格式支持 | 市场太小，建议用户自行转 .docx |
| 多语言（除中英外） | 目标用户是中国外贸人 |
| 移动端 App | Web 端先做好 |
| Docker 化 | 当前 VPS 部署够用 |
