## 已知限制

### 格式支持
| 格式 | 支持情况 | 计划 |
|------|---------|------|
| .xlsx / .xls | ✅ 完整支持 | — |
| .docx | ✅ 完整支持 | — |
| .doc | ❌ 不支持 | 需用户自行转换 |
| .pdf（文字版） | ✅ 完整支持 | — |
| .pdf（扫描件） | ⚠️ 有限支持 | 计划 v0.3 加 OCR |
| .pdf（纯图片） | ❌ 不支持 | 计划 v0.3 加 OCR |
| 图片/照片 | ❌ 不支持 | 计划 v0.3 加 OCR |

### 产品限制
| 限制 | 值 |
|------|----|
| 免费上传文件数 | 3 个（无需注册） |
| 单文件大小上限 | 50MB |
| 解析超时 | 60秒 |
| 单次报价产品数 | 无限制（但页面响应可能变慢） |

### 已知缺陷（P0/P1 待修复）

**P0（运行时崩溃）：**
- `/api/quotation/pdf` — 待修复
- `/api/pi` — 4个未定义变量待修复
- `/api/packing` / `/api/invoice` — `_pro_user` 未定义待修复
- 支付 Webhook — 空密钥可绕过

**P0（中文乱码）：**
- 报价单/PI/装箱单部分中文显示为方框

**P1（体验问题）：**
- 页面错误全部使用 alert() 弹窗
- 10个 fetch 请求无超时保护
- 导出文件无限堆积
- 零重试机制
- 多处静默失败（`except: pass`）

> 完整清单见 `docs/quoteflow-audit-2026-06-29.md`
