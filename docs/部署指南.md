# 部署指南

> 本文档说明 PostgrSQL (Supabase)、Creem 支付、数据迁移的部署步骤。

---

## 1. Supabase 设置

1. 注册 [supabase.com](https://supabase.com) → 创建项目
2. 在项目 Dashboard → Settings → Database → Connection string 获取 `DATABASE_URL`
3. 将 `postgresql://...` 改为 `postgresql+asyncpg://...`（添加 `+asyncpg`）
4. 填入 `backend/.env` 的 `DATABASE_URL`

## 2. 数据迁移

```bash
cd backend
# 确保 .env 中 DATABASE_URL 已配置
python migrate_data.py
```

脚本会从 SQLite（`auth.db` + `~/.product_tool/products.db`）读取数据写入 PostgreSQL。

## 3. Creem 支付设置

1. 注册 [creem.io](https://creem.io) 并获取访问权限
2. Dashboard → 创建 Product：
   - Name: `Product Tool Pro`
   - Price: `CNY 39/month` (recurring)
   - 记住 Product ID（格式 `prod_xxx`）
3. Dashboard → Developers → 获取 API Key + Webhook Secret
4. Webhook URL: `https://yourdomain.com/api/payment/webhook`
5. 填入 `backend/.env`：

```env
CREEM_API_KEY=creem_live_xxx
CREEM_WEBHOOK_SECRET=whsec_xxx
CREEM_PRODUCT_ID_PRO=prod_xxx
BASE_URL=https://yourdomain.com
```

## 4. 完整环境变量清单

| 变量 | 必填 | 说明 |
|------|------|------|
| `JWT_SECRET_KEY` | 是 | JWT 签名密钥（生产环境必须更改） |
| `DATABASE_URL` | 是 | PostgreSQL 连接串（asyncpg 格式） |
| `CREEM_API_KEY` | 否 | Creem API Key（不填则支付功能不可用） |
| `CREEM_WEBHOOK_SECRET` | 否 | Creem Webhook 密钥 |
| `CREEM_PRODUCT_ID_PRO` | 否 | Creem Pro 订阅产品 ID |
| `BASE_URL` | 否 | 部署域名（用于 webhook 回调） |
| `GEMINI_API_KEY` | 否 | AI 解析（可选） |

## 5. Railway 部署

`railway.json` 已内置。需在 Railway Dashboard 设置以上环境变量。

```json
{
  "build": "pip install -r requirements.txt",
  "start": "uvicorn main:app --host 0.0.0.0 --port $PORT"
}
```
