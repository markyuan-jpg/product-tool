# 解析器架构与配置

## 三解析器协同架构

```
          /api/parse 入口 (main.py)
                │
    ┌─────── 按扩展名分发 ────────┐
    │           │           │        │
  .xlsx/.xls   .pdf       .docx    其他
    │           │           │        │
universal_  pdf_handler  doc_    run.parse_
parser.py   → pdf_     parser   file()
(4层策略)   parser.py  (3层策略) (6种专
    │       (4层策略)            用格式)
    │           │           │
    └─────── 择优 (score_result) ──────┘
                    │
              图片匹配 + 后处理
                    │
               返回 products
```

## Excel 解析器 (universal_parser.py)

### 4 层策略

| 策略 | 触发条件 | 适用场景 |
|------|---------|---------|
| **KV 布局** | 参数名含冒号 `Model: S1` | 配置单、参数表 |
| **关键词表头** | 表头含"型号/价格/规格"等 | 标准外贸表格 |
| **内容推断** | 无视表头，分析数据分布 | 无关键词表头的表格 |
| **无表头模式** | header_row ≤ 1 时启用 | 纯数据文件（无表头行） |

### 关键词体系 (COLUMN_SIGNALS)

共约 120 个关键词，覆盖 25+ 行业：

| 行业 | 覆盖词示例 |
|------|-----------|
| 医疗器械 | 型号、规格、批号、产品名称 |
| 电子/电器 | power、voltage、capacity、频率 |
| 服装/纺织 | 款号、色号、尺码、面料、成分 |
| 机械设备 | 功率、压力、转速、行程 |
| 五金/工具 | 材质、表面处理、硬度、工艺 |
| 家具/家居 | 尺寸、颜色、材质、承重 |
| 化工/原料 | 纯度、含量、浓度（通用检测兜底）|
| 食品/饮料 | 净含量、保质期（通用检测兜底）|
| 汽车/配件 | OE no、OEM no、适用车型 |
| 照明/LED | 色温、流明、灯头、显指 |
| 新能源 | 容量、电压、循环寿命 |

### 扩展行业关键词

在 `universal_parser.py` 的 `COLUMN_SIGNALS` 字典追加即可：

```python
COLUMN_SIGNALS = {
    'spec': [
        # ... 已有词 ...
        '你的新关键词', 'your new keyword',
    ],
}
```

改动无需重启服务（热加载）。

## PDF 解析器 (pdf_parser.py)

### 4 层策略

| 策略 | 说明 |
|------|------|
| KV 规格表 | 检测参数名/值格式的表格（≤2列） |
| 布局检测 | 行优先/列优先表格布局自动识别 |
| 内容推断 | `_classify_pdf_columns` 按数据分布分类列 |
| Docling 回退 | `USE_DOCLING=1` 时启用高级 OCR |

### 依赖

- **pdfplumber** (必需)：表格和文本提取
- **PyMuPDF / fitz** (必需)：图片提取
- **Docling** (可选)：`pip install docling` + 设 `USE_DOCLING=1`

## DOCX 解析器 (doc_parser.py)

### 3 层策略

| 策略 | 说明 |
|------|------|
| 表头关键词 | 扫描含"型号/价格"等关键字的行作为表头 |
| 内容推断 | `_infer_docx_columns` 按数据分布分类列 |
| 段落文本 | 无表格时的自由文本提取 |

### 依赖

- **python-docx** (必需)

## 图片匹配

所有解析器统一输出 `_row` + `_sheet` 列，通过 `image.py:match_images_to_products()` 按行列键值匹配图片。

## 评分与择优

### 信号组合评分系统（`backend/score.py`）

不再使用简单的线性公式，改为 **信号组合评分**，每个产品独立打分后取均值，再加全局一致性加成。

#### 逐产品评分（7 级信号组合）

| 条件 | 分值 | 含义 |
|------|------|------|
| 真型号 + 有价格 + 有参数(>30字) | +7 | 最强信号，三个字段对齐 |
| 真型号 + 有价格 | +5 | 强信号 |
| 真型号 + 有参数(>30字) | +4 | 中信号 |
| 真型号（只有型号）| +2 | 可接受 |
| 有价格但无型号无参数 | +1 | 弱信号 |
| 假型号(商品_R/D等) | -3 | 自动生成的假型号 |
| 空型号 + 无价格 | -3 | 噪音行 |
| 型号含冒号或超长(>40字) | -2 | 内容错列 |

**真型号定义**: 2~30字，含字母+数字，不含冒号。

#### 全局一致性加成（扫描完全部产品后）

| 条件 | 加分 |
|------|------|
| 有 ≥3 个不同的真型号 | +3 |
| 有 ≥3 个产品有价格 | +2 |
| 噪音行(分≤-3)占比 < 20% | +1 |

#### 最终公式

```
最终分 = (∑ 单行分 + ∑ 一致性加成) ÷ 产品数
```

#### 选择规则

```
if spec_score > uni_score:
    选专用解析器
else:
    选通用解析器（或保持原有默认）
```

无特殊规则，纯分高者胜。
