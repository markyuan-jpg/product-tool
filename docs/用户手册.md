## 快速入门

### 30秒生成第一份报价单

```
① 打开 https://quoteflow.it.com
② 把工厂报价单（PDF/Excel/Word）拖到上传区域
③ 等待自动解析（约5-30秒）
④ 勾选需要报价的产品
⑤ 点击"生成报价单"
⑥ 下载文件
```

## 详细操作指南

### 1. 上传报价单

支持格式：
- **Excel:** .xlsx / .xls（最佳兼容）
- **Word:** .docx
- **PDF:** 文字版PDF（扫描件暂不完全支持）

**操作：**
- 拖拽文件到虚线区域
- 或点击虚线区域选择文件
- 免费用户最多上传3个文件

**注意事项：**
- 文件大小建议不超过 50MB
- 图片类PDF（扫描件/拍照件）部分支持，文字过少时会提示
- 一个文件里包含多个产品表格的效果最佳

### 2. 解析结果

上传后系统会自动解析，展示解析出的产品清单：

| 字段 | 说明 |
|------|------|
| 型号（Model） | 产品的型号/货号 |
| 名称（Name） | 产品名称（中英文） |
| 规格（Spec） | 产品参数、尺寸、材质等 |
| 价格（Price） | 单价（RMB/USD） |
| 图片 | 报价单中的产品图片 |

**可操作：**
- ✅ 勾选/取消勾选产品
- ✅ 查看解析出的产品图片
- ✅ 查看去重统计（如有重复产品）
- ✅ 点击"试试Demo"预览工具效果（不上传文件也能看）

### 3. 生成单据

选择好产品后，可以生成以下单据：

| 单据类型 | 说明 | 适用场景 |
|---------|------|---------|
| **报价单**（Excel/PDF） | 含产品信息、图片、总价 | 发给客户询价回复 |
| **PI（形式发票）** | Proforma Invoice | 客户确认订单后 |
| **装箱单** | Packing List | 发货时 |
| **商业发票** | Commercial Invoice | 清关用 |

**操作：**
1. 点击底部"生成报价单"
2.（可选）填写公司名称、联系信息
3. 选择导出格式
4. 点击确认 → 自动下载

### 4. 工作台（Workspace）

点击导航栏"Workspace"进入工作台，功能包括：

- **产品库：** 查看所有解析过的产品，可编辑、删除、批量操作
- **报价历史：** 查看之前生成的报价单，可重新下载
- **公司信息：** 设置你的公司名称、地址、银行信息（生成单据时自动填入）
- **模板管理：** 上传你的报价单模板（系统读取模板格式）

## 常见问题

### Q：上传后解析结果为空？
- 检查文件是否是图片/扫描件（当前不完全支持）
- 检查文件是否加密或有权限保护
- 尝试将PDF另存为文字版再上传

### Q：导出的中文变成方框？
- 下载后用 Office Excel/WPS 打开，不要在浏览器预览
- 如果仍有问题，可能是缺少中文字体，联系我们获取修复版本

### Q：免费版有什么限制？
- 每次最多上传3个文件
- 所有单据类型均可生成（无Pro限制）
- 无需注册即可使用

### Q：我的数据安全吗？
- 解析后的产品数据保存在服务器
- 所有连接使用 HTTPS 加密
- 可随时在工作台删除你的数据
