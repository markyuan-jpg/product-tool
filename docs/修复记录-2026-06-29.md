### P1-3 + P1-4：输出文件 + 图片文件无限堆积 → 启动时清理

**文件：** `backend/main.py` 行 310

**改动：** 新增 `_cleanup_old_files()` 函数，应用启动时清理：
- `OUTPUT_DIR`：7 天过期文件
- `product_tool/temp_images/`：14 天过期文件

```python
def _cleanup_old_files(directory, max_age_days=7):
    cutoff = time.time() - max_age_days * 86400
    for f in directory.iterdir():
        if f.stat().st_mtime < cutoff:
            f.unlink()
```
