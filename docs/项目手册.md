## 1. 项目概览

| 项目 | 说明 |
|------|------|
| **谁用** | 外贸 SOHO / 3-5 人小团队 |

| **国际化** | 中/英文双语言支持 |

## 4. 技术架构

```
Browser → Vercel (CDN) → HTTPS → Alibaba VPS (nginx → FastAPI :8000)
                                         ↓
                                    SQLite (默认) / PostgreSQL
```

### 前端
- Next.js 16 App Router，全部 `'use client'` 组件（无 SSR）
- React 19 + Tailwind CSS v4
- Context API i18n（中/英）
- Vercel Analytics + @sentry/browser（可选）

### 后端
- FastAPI async + SQLAlchemy async ORM
- 双解析器架构：通用解析器 + 专用解析器 → 评分选优
- JWT HS256 + bcrypt
- slowapi 限流（nginx `X-Forwarded-For` 感知）
- 邮件：Resend > SMTP > noop 三通道回退

### 数据库
- 默认 `sqlite+aiosqlite:///./app.db`（零配置）
- 可选 `postgresql+asyncpg://...`（生产环境）
- 三张表：`users` `web_products` `web_quotations`

### 目录结构
```
├── backend/           # FastAPI（35 个端点）
├── landing/           # Next.js（13 个页面）
├── product_tool/      # 核心解析引擎
├── scripts/           # 运维脚本
├── docs/              # 文档
└── .github/workflows/ # CI/CD
```

## 5. 部署

### 后端（阿里云 VPS）

```bash
cd /home/admin/product-tool
git clone <repo> .
cd backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
# 创建 backend/.env（见第10节）
nohup venv/bin/python -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2 > app.log 2>&1 &
```

**更新部署：**
```bash
cd /home/admin/product-tool && git pull
cd backend && source venv/bin/activate
pip install -r requirements.txt
pkill -f uvicorn && sleep 2
nohup venv/bin/python -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 2 > app.log 2>&1 &
```

**数据库备份（crontab）：**
```
0 2 * * * /home/admin/product-tool/scripts/backup.sh >> /home/admin/product-tool/backups/backup.log 2>&1
```

### 前端（Vercel）
- Root Directory: `landing`
- 环境变量: `NEXT_PUBLIC_API_URL=https://api.quoteflow.it.com`
- 推送到 master 自动部署

### Creem 支付设置
1. [creem.io](https://creem.io) → 创建产品 → 复制 Product ID
2. Settings → API Keys → 复制 Secret Key
3. Webhooks → 添加 `https://api.quoteflow.it.com/api/payment/webhook` → 复制 Signing Secret
4. 填入 `backend/.env`

## 6. 解析器系统

### 架构

```
输入文件 → 格式检测 → 双解析器并行 → 信号组合评分 → 选优 → 图片匹配 → 返回
                ↓                    ↓
         通用解析器              专用解析器
      (universal_parser.py)   (run.parse_file)
      三层策略:                6种专用解析器
      KV→表格→内容驱动         + 多级 fallback
```

### 评分维度

逐产品 7 级信号组合（真型号+价格+参数→+7）+ 全局一致性加成。分高者胜。

### 格式支持

| 格式 | 支持 | 依赖 |
|------|:---:|------|
| .xlsx / .xls | ✅ | openpyxl |
| .docx | ✅ | python-docx |
| .pdf（文本） | ✅ | pdfplumber + PyMuPDF |
| .pdf（扫描） | ⚠️ | 需 docling + USE_DOCLING=1 |
| .doc | ❌ | 不支持 |

### 关键词体系
120+ 关键词覆盖 25+ 行业（shared_keywords.py）。持续扩展中。

## 7. 已知限制

### 格式
- **.doc** 不支持（需转换工具）
- **扫描 PDF** 需 docling（重度依赖，安装大）
- **纯图片 PDF** 不支持（需 OCR）

### 性能
| 文件大小 | 耗时 |
|---------|------|
| <100行 | <1s |
| 100-1000行 | 1-3s |
| >1000行 | 3-10s |
| >10000行 | 限制 2000 行 |

### 数值限制
- 最大文件：50MB
- 最大行数：2000行
- 最大列数：50列

### 已知 Bug
- **跨表价格匹配**：产品顺序不一致时可能错位
- **合并单元格**：python-docx 返回空字符串
- **多数字单元格**：price 标识缺失时可能取错数字

### 安全限制
| 项目 | 状态 |
|------|:---:|
| API 限流 | ✅ |
| 密码加密 | ✅ bcrypt |
| 验证码 | ❌ |
| 邮箱验证 | ❌ |
| 2FA | ❌ |
| WAF | ❌ |

## 9. 安全策略

### 已实施
| 措施 | 详情 |
|------|------|
| 密码 | bcrypt 哈希 |
| Token | JWT HS256（15分钟 + 7天 refresh） |
| 限流 | 登录/注册 5次/分，解析 20次/分 |
| 传输 | HTTPS + HSTS max-age=63072000 |
| 头部 | X-Frame-Options: DENY, X-Content-Type-Options: nosniff |
| 跨域 | CORS 白名单（特定域名） |
| 输入 | html.escape 清洗产品文本字段 |
| 监控 | Sentry（后端 + 前端） |
| 备份 | 每日自动备份（7天保留） |

### 上报漏洞
请邮件至 **support@quoteflow.it.com**（勿开公开 Issue）。
