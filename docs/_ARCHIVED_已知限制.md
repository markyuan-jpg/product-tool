# 已知限制

## 格式支持

| 格式 | 支持情况 | 依赖 |
|------|---------|------|
| .xlsx | ✅ 完整支持 | openpyxl |
| .xls | ✅ 完整支持 | openpyxl |
| .docx | ✅ 完整支持 | python-docx |
| .doc | ❌ 不支持 | 需转换工具 |
| .pdf (文本) | ✅ 完整支持 | pdfplumber |
| .pdf (扫描) | ⚠️ 有限支持 | 需安装 docling + 设 USE_DOCLING=1 |
| .pdf (纯图片) | ❌ 不支持 | 需 OCR 工具 |

## 依赖与安装

| 依赖 | 必需/可选 | 用途 | 安装命令 |
|------|----------|------|---------|
| openpyxl | 必需 | Excel 读写 | 已预装 |
| python-docx | 必需 | Word 文档解析 | 已预装(1.2.0) |
| pdfplumber | 必需 | PDF 表格提取 | 已预装(0.11.9) |
| PyMuPDF | 必需 | PDF 图片提取 | 已预装(1.27.2) |
| pywin32 | 可选 | Excel→PDF 转换 | `pip install pywin32` |

| reportlab | 必需 | PDF 生成回退 | 已预装 |

## 性能

| 场景 | 表现 | 说明 |
|------|------|------|
| 小文件 (<100行) | <1s | 即时 |
| 中等文件 (100-1000行) | 1-3s | 图片匹配为主要耗时 |
| 大文件 (>1000行) | 3-10s | 受限于 openpyxl 解析速度 |
| 海量文件 (>10000行) | 10-30s | 受限于行遍历上限 2000 |
| 一键生成全部 | 5个请求并行 | 前端 Promise.allSettled |

## 已知 Bug

### Excel 解析器

- **多数字单元格**：`"Size:15x10cm, Price:12.5"` 优先取 price 标识后的数字，但若 price 标识缺失可能取错
- **币种检测**：基于表头和数据判断，极少数场景可能误判

### PDF 解析器

- **跨表价格匹配**：当分表价格按列位置匹配时，如果产品顺序不一致可能匹配错位
- **图片按序号分配**：无精确匹配时按位置分配，可能错位

### DOCX 解析器

- **合并单元格**：python-docx 返回空字符串，不做特殊处理
- **自由文本提取**：仅适用于含明确型号+价格模式的纯文本

## 数值限制

| 参数 | 上限 | 原因 |
|------|------|------|
| 行遍历 | 2000 行 | 防止超大文件卡死 |
| 列扫描 | 50 列 | 防止超大文件卡死 |
| 文件大小 | 50 MB | 上传限制 |
| 连续空行 | 20 行 | 触发扫描终止 |
