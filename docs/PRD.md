## 1. 产品定位

### 一句话定义
**QuoteFlow 是一个面向外贸从业者的报价单自动化工具**——上传工厂发来的报价单（Excel/PDF/Word），自动解析提取产品信息，一键生成发给客户的专业报价单、PI、装箱单、商业发票。

### 目标用户
- **外贸SOHO（个人/小团队）** — 每天处理大量工厂报价单，手动复制粘贴耗时
- **外贸公司业务员** — 需要快速从工厂报价整理出给客户的报价
- **跨境电商卖家** — 管理多供应商产品信息，生成统一格式报价

### 核心痛点
1. 工厂报价单格式混乱，每家供应商格式都不一样
2. 手动从PDF/Excel复制产品信息到报价模板，耗时长且容易出错
3. 同一个产品要给不同客户出不同格式的单据（报价单/PI/装箱单/发票）
4. 多供应商报价单难以统一管理和对比

### 差异化
| 对比 | QuoteFlow | Excel手动做 | 传统ERP |
|------|-----------|------------|---------|
| 学习成本 | 拖拽上传，30秒出结果 | 需要模板和公式 | 需要培训，配置复杂 |
| 价格 | 免费 | 免费 | 几千到几万/年 |
| 灵活性 | 任何格式的工厂报价都能解析 | 每次手动调整 | 需要标准化数据录入 |
| 输出格式 | 报价单/PI/装箱单/发票 | 自己调格式 | 固定模板 |

## 2. 用户故事

### 核心流程（Happy Path）
```
1. 用户收到工厂报价单（PDF/Excel/微信图片）
2. 拖拽上传到 QuoteFlow
3. 系统自动解析出产品清单（型号、规格、价格、图片）
4. 用户勾选需要报价的产品
5. 一键生成报价单（或PI/装箱单/发票）
6. 下载文件，微信/邮件发给客户
```

### 典型场景
**场景1：日常报价**
> 小李是外贸SOHO，早上收到3家工厂的报价单。以前他要把每个报价单打开，复制产品信息到Excel模板，再调整格式。现在他拖进去→30秒→选产品→生成报价单，10分钟的活变成1分钟。

**场景2：多供应商比价**
> 小王做LED出口，3家供应商给了不同格式的报价单。他全部拖进QuoteFlow，系统自动解析出统一格式的产品列表，勾选最优产品组合，一键生成对比报价。

**场景3：订单确认**
> 客户确认订单后，小李直接在QuoteFlow里勾选已确认的产品，切换"PI"模式，生成形式发票发给客户。

## 5. 竞品分析

| 竞品 | 优势 | 劣势 |
|------|------|------|
| **传统Excel模板** | 免费，灵活 | 手动操作费时，易出错 |
| **外贸ERP（孚盟/小满）** | 功能全面 | 贵（几千起），配置复杂，不适合个人 |
| **Zoho Invoice** | 在线发票工具 | 不支持工厂报价解析，面向海外 |
| **WPS表单** | 简单 | 不能解析PDF/Excel，不能批量生成 |

**QuoteFlow 的优势：** 唯一一个专门做"工厂报价→客户报价"这个转化环节的工具，不是大而全的ERP，而是切中一个具体痛点的工具。
