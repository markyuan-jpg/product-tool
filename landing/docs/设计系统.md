# 报价整合工具 — 前端设计系统

> 版本: 1.0 | 最后更新: 2026-05-11

---

## 1. 设计定位

**产品类型:** 外贸 B2B 工具型 Web 应用
**目标用户:** 外贸 SOHO / 3-5 人小团队，需要快速从供应商文件生成专业报价单
**核心体验:** 上传 → 自动解析 → 一键出单，30 秒内完成
**设计原则:**
- **专业可靠:** 深海蓝主色调传递信任感，琥珀金点缀提升品质
- **高效直接:** 核心操作路径不超过 3 步，信息层级清晰
- **数据可视化:** 解析结果即时预览，所见即所得

| 断点 | 宽度 | 布局调整 |

## 5. 组件体系

### 5.1 导航栏 Nav

- 固定顶部，高度 64px
- 左: Logo "报价整合工具" (深海蓝粗体)
- 右: 工作原理 / 定价 / 登录 (或用户名+退出)
- 高亮当前页

### 5.2 上传区域

- 虚线边框，圆角 16px
- 拖拽时: 边框变琥珀金，背景淡金色，轻微放大
- 三种状态: 初始 / 加载中(旋转动画) / 达到上限

### 5.3 三面板组件

每个面板由**左说明区 + 右内容区**组成，竖排排列：

**面板1: 自动解析**
- 左: 产品提取流程说明（4 行简洁文案）
- 右: 产品表格（型号 / 名称 / 规格 / 价格）
- 表格行 hover 高亮

**面板2: 智能报价**
- 左: 报价能力说明（自动配图 / 双语 / 贸易术语 / 汇率）
- 右: 产品卡片网格（图片 + 型号 + 名称 + 数量）
- 卡片 hover 上浮阴影
- 图片懒加载，失败显示占位

**面板3: 全部出单**
- 左: 出单能力说明（一份数据出全套单据）
- 右: 单据列表（5 种类型，带状态标识）
- 每个单据项: 图标 + 名称 + 免费/Pro 标记

### 5.4 文件标签栏

- 横排标签，每个标签显示文件名
- 当前选中的标签: 深海蓝背白字
- 未选中: 灰底深色字
- 最右侧 "+" 按钮继续上传
- 标签切换时三面板数据联动更新

### 5.5 卡片

- 白底，圆角 8px 或 12px
- 边框 `1px solid var(--border)`
- hover: 阴影 `shadow-md`，轻微上移

### 5.6 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 (CTA) | 琥珀金底白字 | 生成报价单、确认操作 |
| 次按钮 | 深海蓝底白字 | 登录、注册 |
| 轮廓按钮 | 边框深海蓝 | 次要操作 |
| 幽灵按钮 | 无背景，只有文字 | 导航链接、取消 |

## 6. 交互与动效

| 触发 | 效果 | 时长 | 说明 |
|------|------|------|------|
| 页面加载 | 面板从下往上淡入 | 0.5s | 错开 0.1s 依次出现 |
| 拖拽文件 | 边框变金色 + 放大 1.02 | 0.2s | 视觉反馈 |
| 标签切换 | 内容交叉淡入淡出 | 0.25s | 平滑过渡 |
| 卡片 hover | 上移 -2px + 阴影 | 0.2s | 可点击感 |
| 行 hover | 浅灰背景 | 0.15s | 表格行引导 |
| 按钮 hover | 透明度 90% / 背景加深 | 0.15s | 点击反馈 |

## 10. 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| CSS 方案 | Tailwind 4 + CSS 变量 | 快速开发，统一设计令牌 |
| 字体 | Noto Sans SC + Inter | 中英文混排的最佳搭配 |
| 配色 | 深海蓝 + 琥珀金 | 传递专业感，避免烂大街的蓝白 |
| 布局 | 左说明右内容三面板竖排 | 信息层级清晰，一目了然 |
| 动画 | CSS only | 零依赖，性能好 |
| Next.js 路由 | App Router | 最新稳定版，性能优化更佳 |
